## ✅ 已完成：第五波「体验重构」（用户试玩反馈，2026-10-09；含第六波平衡与 QA）
1. **经济重做**
   - 初始资金过高 → 第一回合就能做很多事、没有成长感。新俱乐部与真实俱乐部的起始资金都要下调（新俱乐部约 6–8 回合工资；豪门约 1 个赛季工资）。
   - 收入来源太少、奖金入不敷出 → 核实奖金是否合理：目前奖金按真实美元 1:1 发放，TI4–TI10 众筹奖池（最高 4000 万）让夺冠后金币失去意义，而中下游战队几乎拿不到奖金。
   - 方案：奖金按年代压缩换算为游戏金币（显示真实奖池，发放压缩后的金额）；奖金覆盖更多名次；新增每回合的赞助 / 直播内容 / 周边收入（随荣誉、名次、明星选手、近期冠军浮动），在财务页按来源清晰展示。
   - 目标：中游战队大致收支平衡，强队有盈余，新俱乐部需精打细算但能靠成绩与卖人成长；额外训练 / 训练赛 / 抽卡是有意义的取舍而不是随手可买。
2. **赛季前大型转会潮**：像现实 Dota 社区一样，每届 TI 后都有一轮大规模、活跃的转会（成绩不达预期的队伍换 1–3 人、明星追求更强的队伍、豪门挖角、自由选手与新秀上位、偶有战队解散或新组织入场），并产生大量转会新闻与传闻，避免打了三四届 TI 头部队伍都不变动。
3. **跨赛季数值波动**：每个赛季选手状态有起伏（赛季状态修正 + 年龄趋势 + 随机噪声），体现不同赛季的多样性；按现实规律校准：一般有几个赛季的衰退期而不是断崖（去年冠军不至于今年小组赛出局），加强年龄衰退的影响，不同位置巅峰年龄不同（辅助巅峰更晚）。
4. **界面精简**：信息量大、俱乐部运营与比赛要来回切换很多页面 → 合并导航为少数几个带标签页的中心页（总览 / 战队 / 转会 / 赛事 / 俱乐部 / 消息），常用操作尽量在总览通过弹窗完成，底部操作栏引导流程。
5. **新闻存在感**：模拟过程中看不清其他队伍的发展和社区变化 → 世界动态流、每回合要闻、刀塔周报（实力榜变化、热门选手、转会传闻）、重大事件提示；新闻带战队/选手链接，可点击查看。

## ✅ 已完成：第八波「管理难度与公平性」（用户决策，2026-10-09）
1. **隐藏的预期薪资**（不在界面显示数值）
   - `expectedSalary(state, player)` = 当前市场工资 × 荣誉系数(所在战队荣誉，荣誉越高增长越快：凸函数) × 明星系数(天梯等级、近期冠军/MVP)。
   - 薪资差 g = (预期 − 实际) / 预期。差距越大、且越拉越大 → 归属感下降越快、滋生不满（公开新闻「XX 对薪资不满」）、外部战队挖角概率提高（AI 报价权重 ∝ g）。
   - 续约时选手要价 ≥ 预期薪资；加薪可缩小差距。界面只给定性情绪提示（满意 / 略有不满 / 强烈不满），不显示数值。
2. **取消抽卡，改为 NBA 式新秀选秀**
   - 每个赛季开始固定引入一批新人（本赛季登场的真实新秀 + 程序生成新人），所有战队（含玩家）参加选秀，自动进行。

   - 各队按顺位自动挑选（兼顾实力与位置需求，带随机性）；**不因阵容人数放弃顺位**（2026-10-09 用户反馈后修改）：玩家战队保留全部新秀、由经理决定首发与替补，

### 9. ✅ 懒人模式自动补员（v0.3 终验，2026-10-15；`dev/v0.3`）
终验发现：选秀被付费抽卡取代后，只按「下一回合」的人类战队（懒人推进；多人的自动准备与房主托管同一路径）再也得不到新人，12 局中 TI12 时正式阵容 0~3 人（两局 0 人；v0.2.1 同种子 5~10 人），

  为缺失的位置签下评分最高、预算允许、本回合不会婉拒（与手动签约同一枚谈判骰子）的自由选手，不超过常规阵容上限 8 人。每个空缺分两轮挑人：先在签下后经常性收入（赞助 + 直播 + 周边）
