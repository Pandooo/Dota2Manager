# 刀塔经理 · Dota2 Manager

> 接管真实豪门俱乐部，亦或白手起家打造护国之翼。训练、转会、新秀、BP 博弈、文字直播——让你的战队捧起不朽盾！

一款在浏览器中运行的 Dota 2 电竞俱乐部经营模拟游戏（灵感来自《足球经理》）。你扮演俱乐部经理，从 TI1（2011）到 TI16（2027）之间任选起止届次，组建战队征战每年的巡回赛，以夺得 The International 冠军为目标。支持单机与局域网多人对战。

**版本：v0.4.3**（更新内容见文末「更新日志」）

---

## 特色

- **真实历届阵容**：TI1–TI15 共 15 届的真实战队与选手数据（参考 Liquipedia 整理），可接管当年的真实俱乐部或新建俱乐部；真实选手会沿着各自的真实生涯轨迹成长，未来出道的真实新秀会在对应赛季进入新秀卡池。
- **完整的经营循环**：赛季日历（休赛回合 / 赛事回合 / TI 预选 / TI 正赛，赛季中可报名或退出尚未开赛的赛事）、训练与训练赛、新秀抽卡（真实新秀 / 请神新秀 / 虚构新秀，名人堂收录 DotA1 时代传奇与历届 SS / SSR 选手）、自由市场与转会（可用「现金 + 本队选手抵价」交易）、挂牌出售、教练、奖金分成、隐藏的预期薪资与多维归属感、荣誉系统（荣誉跌破 0 即解散，荣誉势头影响赛季状态）。
- **比赛模拟**：队长模式 BP（可手动或自动）→ 大老师胜率 → 结合选手数值的随机胜负 → 中文文字直播；也可一键快速模拟。
- **动态世界**：按真实发布日期逐回合生效的 Dota 2 版本更新、赛季前大型转会潮、跨赛季状态起伏与年龄衰退、随机事件（签证、伤病、丑闻、假赛……）、刀塔周报与世界动态新闻。
- **懒人模式**：底部「下一回合」可自动处理本回合的比赛、阵容（缺人时签下负担得起的自由选手）与待决事件，一路点到底也能玩完一个赛季。
- **DotaPedia 百科**：仿 Liquipedia 的战队页与选手页、KDA 等历史数据、各类排行榜，以及实时的「历史地位」评估。
- **生涯总结**：游戏结束时按成就生成《文明》式结算，与历史真实俱乐部对照排名。
- **多人对战**：局域网内由房主启动服务器，或部署到公网服务器，朋友用浏览器加入房间；共享回合、操作按到达顺序实时结算（例如抢签同一名自由选手先到先得）。
- **俱乐部生态**：资金链断裂会破产出局；联赛中会陆续涌现新的真实俱乐部，每家真实俱乐部都背负一个「使命」（集齐其历史巅峰阵容）；俱乐部名称与队徽随真实品牌时间线更替。
- **羁绊系统**：历届冠军 / 经典阵容的成员同队首发时获得对应加成（战斗力、灵性、韧性、天赋、天梯等）。
- **背景音乐**：内置浏览器实时生成的原创氛围音乐，也可以选择本地音频文件播放（只存在本浏览器，不上传）。
- **手机可玩**：手机浏览器（竖屏与横屏）有专门的导航抽屉、三行底部操作栏、底部弹出的弹窗与可滑动的表格，触屏点按即可看到说明；可以「添加到主屏幕」全屏打开。

## 快速开始

需要 Node.js 20+（开发时使用 Node 22–25 验证）。

```bash
npm install
```

### 单机

```bash
npm run dev
```

浏览器打开终端里显示的地址（默认 http://localhost:5173）。进度自动保存在当前浏览器（匿名会话，IndexedDB），可在游戏内导出 / 导入存档文件。

### 局域网多人

房主在项目目录运行（会先构建前端，再在 8686 端口启动服务器）：

```bash
npm run mp
```

终端会打印本机的局域网地址，朋友在同一局域网内用浏览器打开该地址即可进入大厅。详细说明见 [docs/MULTIPLAYER.md](docs/MULTIPLAYER.md)。

也可以部署到自己的云服务器：`scripts/deploy.sh user@host`（同步源码、安装依赖、构建并以 systemd 服务运行；服务以 `--public` 公网模式启动，不向玩家暴露内网地址），见 [docs/MULTIPLAYER.md](docs/MULTIPLAYER.md)「部署到公网服务器」。服务监听 80 端口（v0.4 起），玩家在电脑或手机浏览器打开 `http://<服务器地址>/` 即可，不用写端口；过渡期同时保留旧地址 `http://<服务器地址>:8686/`。在服务器上用 `curl -s http://127.0.0.1/api/status` 查看当前在线人数（只允许服务器本机访问；另有日志与每日汇总，见 MULTIPLAYER.md §14）。

## 常用命令

| 命令 | 作用 |
|---|---|
| `npm run dev` | 开发服务器（单机） |
| `npm run build` | 类型检查 + 生产构建（输出 `dist/`） |
| `npm run mp` | 构建并启动局域网多人服务器 |
| `npm run server` | 仅启动多人服务器（需已构建 `dist/`） |
| `npm test` | 运行全部单元测试（Vitest） |
| `npm run typecheck` | TypeScript 类型检查 |
| `npm run sim -- --ti 9 --seasons 3 --seed 1` | 无头模拟整局游戏（平衡调试，支持 `--team <战队id>`、`--runs N`、`--quiet`） |
| `npx tsx scripts/smoke-match.ts 9` | 手动比赛流程冒烟测试 |
| `npx tsx scripts/simulate-mp.ts --mode both` | 无头多人对局模拟 |
| `npm run mp:e2e` | 多人端到端测试（真实服务器 + 多个客户端） |
| `npm run data:validate` | 校验 `src/data` 中的数据 |
| `npm run data:index` | 由各届阵容重建真实新秀索引 `playerIndex.json` |

## 技术栈与结构

- **引擎**：纯 TypeScript，确定性模拟（存档内保存随机种子），可在浏览器与 Node 中运行。
- **界面**：React 19 + Tailwind CSS v4 + Zustand，全中文。
- **多人**：Node + `ws` 的权威服务器，复用同一套引擎。

```
src/
  engine/   模拟引擎（赛季流程、比赛与 BP、成长、经济、市场、新秀抽卡与名人堂、事件、新闻、多人座位……）
  data/     静态数据（TI 信息、各届阵容、版本、英雄、赛事、历史俱乐部……）
  store/    状态管理、会话存档、联机客户端
  ui/       页面与组件
  shared/   服务器与客户端共享的联机协议
server/     局域网多人服务器
scripts/    无头模拟、数据构建与校验、端到端测试
tests/      单元测试
docs/       设计文档
```

## 本地队标 / 冠军盾（可选）

真实战队队标与官方冠军盾图片属于各自权利人的商标 / 版权美术，本仓库不分发；游戏默认显示按品牌配色生成的原创风格化队徽与原创矢量冠军盾。想在自己的电脑上换成别的图片时：

- 队标：放到 `public/local/logos/{战队 id}.png`（或 `.svg` / `.webp`，战队 id 见 `src/data/rosters/ti*.json`，例如 `og.png`、`team-spirit.svg`）；
- 冠军盾：放到 `public/local/aegis.png`（或 `.svg` / `.webp`）。

`public/local/` 已被 git 忽略（只提交其中的使用说明 `README.txt`），放入或删除文件后重新运行 `npm run dev` / `npm run mp` 即可生效。请只使用你有权使用的图片。

## 更新日志

> 游戏内右上角的版本号（如 `v0.4.0`）也可查看更新说明；更新内容的事实来源为 `src/ui/changelog.ts`，本节为同步副本。

### v0.4.3

- **没被抽中的真实新秀直接进入自由市场**：第 1 回合开始时，赛季初没有被抽走的真实新秀以自由身进入自由市场，不再直接加盟其现实中的出道战队；当回合 AI 战队不会签约他们，你可以先签。出道前在你的战队担任主教练的真实新秀继续执教、暂不出道，解除其主教练职务后进入自由市场。
- **中途复出的真实选手在当届赛季初进入自由市场**：现实中在某一届重返或加入职业赛场、本局还没有出现过的真实选手（如 TI6 开局时 TI8 重返赛场的 Ceb），在该赛季初以自由身进入自由市场（当回合 AI 战队不签、下一回合结束时 AI 接手）；他那几届若在 AI 战队担任主教练会先卸任，在你的战队担任主教练则继续执教，解除其主教练职务后入场。自由选手列表里这些选手标有「新入场」。
- **新入场的真实选手在入场的下一回合结束时由 AI 接手**：仍是自由身的新秀与复出选手，先由他当届现实中效力的 AI 战队签回（需付得起、有空位、谈判成功，例如 OG 签回 Topson、Ceb；出道赛季的新秀按新秀合同签回，无签字费），否则由需要他这个位置的 AI 战队签下；在那之前（包括下一回合内）AI 战队不会用其他方式签他，你仍可以先签。你执教的战队即使是他的真实战队也不会替你自动签下（他入场时总览「通知」会提醒你）。
- **读档补录当前赛季缺失的真实选手**：读取旧存档后，当前赛季现实中在打职业、但本局还没有出现过的真实选手以自由身进入自由市场：读档的这个回合 AI 战队不签，下一回合结束时 AI 战队接手；在 TI 预选赛 / TI 期间读档的，下个赛季初转会窗口开放的那个回合 AI 战队不签，你可以先签，第 1 回合结束时 AI 战队接手（当届真实战队优先）。他们若在 AI 战队担任主教练，该队随即聘请新的主教练；旧存档里待决的「真实新秀希望加盟」事件改为该新秀直接进入自由市场。

### v0.4.2

- **真实选手不再提前退役**：真实选手在现实中的职业生涯结束之前不会退役（例如现实中打到 TI14 的选手，TI13 及之前的赛季结算都不会退役），冠军阵容羁绊与俱乐部使命不再因为成员提前退役而凑不齐；现实生涯结束之后照旧按年龄与状态退役。
- **提前退役者复出**：读取旧存档后，此前已提前退役、现实中职业生涯仍在继续的真实选手宣布复出，以自由身回到转会市场，水平不高于现实中当年的水平；退役后在 AI 战队担任主教练的卸任复出，在你的战队担任主教练的继续执教，在他现实生涯结束前解除其主教练职务即可复出。

### v0.4.1

- **提示位置**：操作提示统一显示在顶栏下方，不再遮挡底部的操作按钮。
- **提示数量**：界面上同时最多显示 2 条提示，新的一条出现时最早的一条提前渐隐消失（多人模式下其他玩家的动态也计入）。

### v0.4

- **手机适配 · 导航**：手机浏览器（竖屏与横屏）可以完整地玩。屏幕较窄时侧栏收进左上角 ☰ 打开的导航抽屉，每个入口下方写明用途，有待处理事项时 ☰ 上有提示点；「存档管理」与「更新说明」也在抽屉底部。
- **手机适配 · 操作栏**：手机上的底部操作栏分三行——本回合提示（点按看全文）、可左右滑动的本回合操作，以及「自动」开关、通栏的「下一回合」与「更多」。比赛页在手机上把记分板与文字直播排在最前，BP 改为「点按选中、再点一次确认」。
- **手机适配 · 弹窗与表格**：弹窗在手机上从屏幕底部升起，确认气泡不会盖住按钮；宽表格可以左右滑动并固定选手 / 战队名一列，转会市场、赛事列表、单局纪录等在手机上改为卡片或分行列表；页面里不再有吞掉滑动的小滚动框。
- **手机适配 · 触屏提示**：点按不可用的按钮会显示原因，原本只在鼠标悬停时显示的说明在手机上直接写出或点按显示；按钮与输入框按手指大小加大，输入时页面不再放大。
- **添加到主屏幕**：可以在手机浏览器里「添加到主屏幕」，之后像应用一样全屏打开（冠军盾图标），并避开刘海与底部横条。
- **公网服务器改用 80 端口**：直接打开 `http://<服务器地址>/` 即可，不用再输入「:8686」。浏览器里的单机进度与多人身份按网址分开保存，旧地址 `http://<服务器地址>:8686/` 过渡期内仍可打开（同一个服务器、同一批房间）：进行中的多人对局请回旧地址继续；单机进度可在旧地址「存档管理 › 导出存档文件」，再到新地址主菜单「导入存档」。
- **部署**（只写在 README，不在游戏内更新说明中）：`deploy/dota2manager.service` 改为 `--port 80 --also-port 8686`，以普通用户 `d2m` 运行、只授予绑定低端口的能力（`AmbientCapabilities=CAP_NET_BIND_SERVICE`）；云服务器安全组需放行 TCP 80。服务器新增 `--also-port`（同一进程同时在其他端口提供服务，换端口时过渡用）；手动连接其他服务器时，`地址:80` 与 `http://地址/` 不再被改成 8686 端口。

### v0.3.1

- **新加入选手随队满 10 场比赛且入队满 6 个转会回合后才能挂牌**：选手加盟后（签约自由选手、转会、交易、抽卡等任何途径），所在战队打满 10 场系列赛（不要求他本人上场）、并且他入队满 6 个转会回合（每个常规赛回合结束时计一次，赛季初与 TI 期间不计），两个条件都满足才能挂牌出售；在此之前其他俱乐部也不会主动求购他，解约不受影响；开局时已在队的选手不受限制。选手详情的挂牌面板显示「比赛 N / 10 场 · 转会回合 M / 6」，阵容页批量挂牌会列出跳过的选手与原因；刚从自由市场签下或本队抽卡得到、尚未满足这两个条件的选手作为交易抵价时同样只按签字费估值。
- **服务器在线统计接口只允许本机访问**：`/api/status` 只回答服务器本机的请求（在服务器上 `curl -s http://127.0.0.1:8686/api/status`），外部访问返回 403；大厅显示的在线人数不变。

### v0.3

- **选手交易**：转会报价可以用「现金 + 本队选手抵价」，一次最多 3 名本队选手，每人按「身价 × 系数」折算（对方缺该位置或能顶替其首发时溢价，位置重叠、年龄偏大或等级低于其首发时折价；不愿加盟对方的选手会被拒收，刚从自由市场签下的选手与入队不满一个赛季的抽卡新秀只按签字费估值）；对方阵容超员时放走一名替补腾出位置。
- **赛季中报名 / 退赛**：本赛季尚未开赛的常规赛事在赛季中随时可以报名、重新接受已婉拒的邀请或退出（TI 与 TI 预选赛仍必须参加）；退出按赛事等级扣荣誉（Major 40 / 顶级赛事 25 / Minor 12 / 线上公开赛 5，距开赛 3 个回合及以上减半），报名或接受邀请的同一回合内退出不扣。总览新增「赛事报名」卡片。
- **补充邀请**：每回合结束时，本赛季积分榜靠前或荣誉达到受邀线、但还没有受邀的战队会收到即将开赛赛事的补充邀请（默认接受，收到的回合内婉拒不扣荣誉）。
- **荣誉势头**：荣誉的同比变化在赛季初调整全队的赛季状态（最多 ±3%），近几个回合的荣誉升降影响战队评分（最多 ±2%）；阵容页、战队详情与总览显示「强势 / 向好 / 平稳 / 走低 / 低迷」。
- **新秀抽卡回归并取代选秀**：卡池包含真实新秀（能力与成长参照真实生涯）、请神新秀（复制名人堂原型的成长走势、巅峰与天赋）和虚构新秀；出卡概率 SSR 5% / SS 10% / S 10% / A 15% / B 30% / C 30%，每 100 抽必出 SSR，单抽价格随年代变化、十连 = 10 次单抽，本回合抽到的新秀可在同一回合内退回；新秀合同工资有上限，入队满一个赛季前不能挂牌出售；单抽 / 十连总是抽满，阵容可以因此超过 12 人的上限，但超编时需在本回合内放弃新秀或解约、退回 12 人后才能进入下一回合（开启「自动处理」时按「下一回合」先自动退回评分最低的新秀）；真实新秀只在赛季初可抽，第 1 回合开始时没被抽走的真实新秀加盟其真实出道战队（出道战队是你的战队时由你决定签下或放弃）；AI 俱乐部按自身资金与阵容空位自动抽卡；卡池在 TI 预选赛转会锁定时关闭。选秀默认关闭，代码保留一个版本。
- **名人堂**：初始收录 DotA1 时代的传奇选手；从 TI1 之后的届次开局时补录开局之前真实历史中达到过 SS / SSR 的选手（只登记到开局为止的成绩，不剧透）；每个赛季结束时引入该赛季的 SS / SSR 选手，作为此后请神新秀的原型；DotaPedia 新增「名人堂」标签（可按 DotA1 时代 / 真实数据补录 / 本局入堂筛选）与选手词条的「名人堂与请神」章节；旧存档读取时自动补录。
- **懒人模式补员**：开启「自动处理」一直点「下一回合」时，转会窗口内正式阵容缺位置或不足 5 人，会自动签下负担得起、愿意加盟的自由选手补位（优先签下后收入仍付得起工资的人选；不会自动抽卡；资金紧张时照旧由临时替补顶上，并说明原因）；按下前按钮提示列出人选与签字费。
- **更新说明与 New 徽标**：右上角的版本号与主菜单页脚的版本号可以打开各版本的更新内容，新功能入口旁带「New」徽标；手机宽度下顶栏不再溢出。
- **多人**：大厅显示服务器当前在线人数、对局数与房间数，房间页顶栏（电脑端）显示在线人数；公网模式（`--public`）不再向玩家显示或发送内网地址，发给玩家的错误提示不含服务器内部细节；同一公网地址的连接数、等待中的房间与开局次数有上限，聊天限速，房间数满时清理长时间无人在线的对局；抽卡与报价结果无法从客户端提前算出（随机数状态与谈判密钥只留在服务器）；主菜单入口改名为「多人对战」。
- **一键部署**（只写在 README，不在游戏内更新说明中）：`scripts/deploy.sh user@host` 把多人服务器部署到自己的云服务器并以 systemd 服务运行（公网模式）；服务器上可用 `/api/status`、日志与每日汇总查看在线人数（见 docs/MULTIPLAYER.md §14）。
